# M6 locked rendering

All HTML originates in a versioned Jinja2 template with auto-escaping and a second allowlist sanitizer (nh3). LLMs are permitted to supply **structured field values only**, never markup or scripts. No inline styles, external fonts, frames, forms or links. The template skips missing sections, supports dir=auto, and truncates huge compatibility tables with an explicit omitted-row notice.

A sanitized HTML fragment is not evidence that the underlying facts are true, that the listed conditions meet all marketplace policies, or that shipping terms have been verified. The shipping/returns text is deliberately a placeholder rather than invented shipping terms.
