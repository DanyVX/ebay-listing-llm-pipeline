# M4 deterministic compliance

Rules consume a strict ListingDraft, a validated source row, and policy metadata. Each violation carries a code, field, severity and reason. Errors **block** export in later orchestration; warnings remain visible.

Local protections include title length, shouting, keyword stuffing, emoji/markup, contact URLs/emails/phones, unsupported promotional/OEM claims, brand/MPN mismatches, ungrounded universal compatibility, keyword duplication and numeric category ID claims. Tests include positive and negative cases.

**Limitations:** This engine is not legal compliance certification or complete VeRO review. Marketplace/category-specific item-specific limits remain unknown until obtained from the official taxonomy API. Unsupported phrases with Unicode homoglyphs are only partially normalized. Numeric specs are checked independently in M5. Heuristics can generate false positives.
