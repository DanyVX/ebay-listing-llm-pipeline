# Data provenance and license

Only *invented* rows such as `data/sample/synthetic.csv` may be committed. No supplier prices, supplier names, real SKUs, store names, order information, real listings, dashboard images, or confidential software logic.

`data/sample/synthetic.csv`: generated by project authors, fictional fixture data, MIT-released with this repository. No external dataset used. No pretrained model downloaded or licensed in M0.

M0 runtime dependency licenses inspected from installed package metadata (2026-10-10): pydantic 2.13.5 MIT, pydantic-settings 2.14.1 MIT (2.14.2 upgrade pending metadata reconfirmation), PyYAML 6.0.3 MIT, typer 0.26.3 MIT, rich 15.0.0 MIT. CI/development tooling and transitive dependencies need a full license audit before release. The packaging toolchain is pinned to setuptools 83.0.0 after the CI vulnerability audit; its license will be checked during release review. Any AGPL, research-only, non-commercial, or restricted future model must be flagged before adoption.
