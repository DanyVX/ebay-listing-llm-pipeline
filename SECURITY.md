# Security policy

This is a research project, not a safe-by-default eBay publishing product. Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting if enabled; otherwise open an issue **without** exploit details or sensitive data, and request a private contact channel.

Never post credentials, real seller/customer data, proprietary prompts or live listings in issues/PRs. Rotate a credential immediately if exposed; deleting a commit does not revoke it. Run secret and history scans before pushing. Treat all supplier strings as untrusted data.
